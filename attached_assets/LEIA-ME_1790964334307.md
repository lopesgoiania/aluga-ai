# Pacote para Replit Design — Painel Eva

## Arquivos

- `PROMPT-MASTER-REPLIT.md`: briefing completo, pronto para colar no Replit.
- `design-tokens.json`: paleta extraída das referências e variáveis semânticas propostas para a interface.
- `referencias/01-dashboard-visual.png`: direção de dashboard e acabamento visual.
- `referencias/02-crm-kanban.png`: direção de CRM em quadro.
- `referencias/03-atendimento-referencia.svg`: direção de caixa de entrada/conversa; contém marcas de terceiros apenas como referência visual.

## Como usar

1. No Replit Design/Canvas, anexe as três referências e `design-tokens.json`.
2. Cole o conteúdo de `PROMPT-MASTER-REPLIT.md` como prompt principal. Se o campo de prompt tiver limite, anexe o arquivo e peça para segui-lo integralmente.
3. Peça primeiro as telas Visão geral, Atendimentos, Fila humana e Alertas. Revise essas telas, incluindo a versão móvel, antes de expandir para as demais.
4. Depois peça para transformar o design em aplicativo web com código executável e confirmar que o build passa. Um frame de Canvas sozinho não é o projeto exportável que será integrado.
5. Exporte ou sincronize o **código-fonte completo**, incluindo manifesto de dependências, assets e instruções de execução. Git/GitHub facilita as revisões posteriores; um ZIP do projeto completo também serve.
6. Coloque o projeto exportado em uma pasta local e compartilhe o caminho. A integração real com Supabase, Evolution e n8n será feita nessa etapa posterior.

Não envie chaves de produção nem dados reais de clientes ao Replit para gerar o visual. A integração deve preservar o banco operacional `aluga-ai`, o catálogo separado `Buscaimóveis` e os workflows já publicados.
